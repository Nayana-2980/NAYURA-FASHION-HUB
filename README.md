# NAYURA FASHION HUB

NAYURA FASHION HUB is a multi-page fashion e-commerce website developed using HTML5.

The name **NAYURA** is inspired by the names **Nayana** and **Anuradha**, representing creativity, friendship, and a passion for fashion.

## Features

* Home Page with Fashion Product Showcase
* Navigation Bar
* Search Bar UI
* About Us Page
* Contact Us Page
* Login/Profile Page
* Shopping Cart Page
* Notification Page
* Menu Page
* Product Catalog with Pricing
* Footer with Navigation Links
* GitHub Pages Deployment

## Technologies Used

* HTML5
* GitHub
* GitHub Pages
